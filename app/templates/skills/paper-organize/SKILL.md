# 论文智能归类

目标：读已有材料再决定归属，优先落在现有分类里，只有在确无合适分类时才提出新目录名。目录与文献归属一律由工具改动，不手写路径。

## 1. 先看现有目录

1. 调用 `library_categories` 获取当前分类与子文件夹树，记下真实目录名（含 `01_` 这类编号前缀）和各级文献数。
2. 判断是否已有语义匹配的分类或子分类。同名或近义的分类直接复用，不为一次性任务新建目录。

## 2. 再读已有材料

1. 确认目标论文：优先用当前打开的文献，其次是用户选中或明确给出的 `L` 编号。
2. 读笔记优先：用 `read_library_doc` 读取该文献关联的 `notes/` 文件，必要时分段读取。
3. 读译文其次：用 `read_paper_translation` 读取与当前原文匹配的最新已完成中文精读，长译文按需用 `offset`/`limit` 分段，先看标题、摘要、引言与结论即可判断主题；工具返回 `available: false` 说明尚无译本。
4. 两者都没有时明确告知用户，并询问是否改为阅读原文首页（`read_paper_pages`）后再归类。不要仅凭文件名猜测主题。

## 3. 定目标目录

1. 优先匹配已有顶层分类或子分类；确无合适分类时，按库内命名习惯拟定简洁的新分类名，不过度拆分。
2. 新名称用中文或已有缩写，长度不超过 60 个字符，不能包含 `/ \ : * ? " < > |`，也不能是 Windows 保留名。
3. 论文已经位于目标目录时不必提案。

## 4. 提交确认卡片

1. 调用 `propose_paper_classification`，每项填写 `paperId`、`category`、可选 `subcategory`、`basis`（`notes`、`translation`、`notes+translation` 或 `pdf`）与 1–300 字中文 `reason`。
2. 该工具只生成待确认卡片，返回 `pending_confirmation` 后在聊天中简要说明依据与目标目录，并提示用户在卡片上确认。
3. 工具确认前不得声称已经新建文件夹或已移动论文：用户点击确认后，服务端才会先创建缺失的目录，再逐篇移动并同步索引与引用。
4. 只有用户明确指定了目标目录或要求免确认直接执行时，才依次调用 `create_category` 与 `move_paper`/`move_papers`。
5. 多篇论文可按目标分组放进同一次提案；用户取消时不要重试，改问缺少的决定。
